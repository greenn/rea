# REA frontend

Исходное задание для текущего этапа:

- тёмный интерфейс в цветах референса Cliptay, немного светлее исходного;
- без отдельного бокового меню: слева сразу список аудиозаписей;
- записи группируются по названию группы / reference;
- в центре выбранная запись, waveform и расшифровка;
- справа заметки и metadata файла/группы;
- перемещение по waveform синхронно прокручивает расшифровку к соответствующему месту;
- таймкоды находятся в отдельной колонке от текста;
- расшифровку можно читать и редактировать;
- отображаются спикеры;
- заметки можно добавлять и редактировать;
- metadata содержит группу/reference, дату, purpose, количество файлов, имя файла, длительность, формат и размер;
- отдельный экран загрузки поддерживает несколько файлов, drag-and-drop, удаление файлов, название группы, дату, purpose/reference и Add to app;
- после добавления группа появляется слева со всеми своими файлами;
- текущий этап: качественный UI, состояния и frontend-логика без усложнения backend и CRM.
