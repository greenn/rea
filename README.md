# REA

Локальное приложение для работы с группами аудиозаписей и единая локальная точка доступа к Whisper.

Версия: **0.1.4**.

## Что реализовано

- интерфейс на основе макета из `blank/ui1g`;
- пустое рабочее пространство без демонстрационных записей и мок-данных;
- группы записей в левой панели;
- загрузка нескольких аудиофайлов через выбор файлов или drag-and-drop;
- локальное хранение аудио, метаданных, заметок и расшифровок в IndexedDB браузера;
- воспроизведение, waveform и переход по позиции записи;
- ручное чтение и редактирование расшифровки;
- заметки и metadata;
- поиск по списку записей;
- встроенный локальный Whisper API на том же адресе, что и REA;
- фоновые Whisper jobs с прогрессом;
- модели `small`, `medium`, `large-v3`;
- распознавание как загруженных аудиофайлов, так и медиа по URL;
- совместимость с существующим Whisper-клиентом CC.

## Основной локальный запуск

На Windows достаточно запустить:

```text
start-rea.cmd
```

При первом запуске скрипт:

1. создаст локальную `.venv`;
2. установит зависимости из `server/requirements.txt`;
3. запустит REA на:

```text
http://127.0.0.1:18787
```

Интерфейс и Whisper API работают через один процесс и один порт.

Проверка сервиса:

```text
http://127.0.0.1:18787/health
```

Основной namespace API:

```text
http://127.0.0.1:18787/api/whisper
```

## Whisper API

Основные endpoints:

```text
GET  /health
GET  /api/whisper/health
GET  /api/whisper/models
POST /jobs
POST /api/whisper/jobs
POST /api/whisper/jobs/file
POST /api/whisper/orthography
GET  /jobs/{id}
GET  /api/whisper/jobs/{id}
POST /api/whisper/jobs/{id}/cancel
POST /api/whisper/jobs/cancel-all
POST /transcribe
POST /api/whisper/transcribe
```

`POST /jobs` принимает URL медиа и возвращает `job.id`. Работа продолжается в фоне. Состояние читается через `GET /jobs/{id}`.

`POST /api/whisper/jobs/file` принимает локальный аудиофайл через multipart upload. Этот endpoint предназначен для REA и других локальных клиентов.

`POST /api/whisper/orthography` корректирует орфографию и пунктуацию уже готовой расшифровки через локальный AIB. Тайминги и спикеры остаются в REA; AIB получает и возвращает только текст сегментов.

`POST /api/whisper/jobs/cancel-all` останавливает текущую задачу и отменяет все ожидающие в очереди задачи.

## Использование из CC

CC уже использует локальный Whisper по адресу:

```text
http://127.0.0.1:18787
```

REA сохраняет совместимые endpoints `/health`, `/jobs`, `/jobs/{id}` и `/transcribe`, поэтому для переключения CC на REA менять адрес не требуется.

Теперь схема такая:

```text
CC ───────┐
          ├── http://127.0.0.1:18787 ── REA ── faster-whisper
REA UI ───┘
```

Whisper больше не должен быть отдельным сервисом внутри CC.

## Модель Whisper

По умолчанию REA использует:

```text
large-v3
CPU
int8
```

Модель загружается только при первом распознавании. Если предыдущий Whisper использовал стандартный Hugging Face cache, `faster-whisper` автоматически переиспользует уже скачанную модель — переносить гигабайты в Git не нужно.

Если старая модель лежит в отдельной директории, можно указать её через переменную окружения:

```text
REA_WHISPER_MODEL_DIR=ПУТЬ_К_КЭШУ_МОДЕЛЕЙ
```

Другие настройки описаны в `.env.example`.

## Орфография через AIB

Кнопка `Ortho` использует локальный AIB по адресу `http://127.0.0.1:8181` и модель `qwen3:4b`. Для запуска сервиса:

```powershell
cd J:\dv\aib
powershell -ExecutionPolicy Bypass -File .\local\start.ps1
```

Если AIB выберет другой порт, укажите его в `REA_AIB_URL` в файле `.env` REA и перезапустите `start-rea.cmd`.

Модели и `.venv` не коммитятся в Git.

## Frontend-разработка

Vite остаётся для отдельной разработки frontend:

```bash
npm install
npm run dev
```

Но обычный рабочий запуск REA + Whisper выполняется через `start-rea.cmd` на порту `18787`.

## Данные

Пользовательские записи, metadata, заметки и расшифровки REA сохраняются в IndexedDB текущего браузера.

Файлы, которые временно передаются Whisper для распознавания, создаются во временной директории и удаляются после завершения job.

REA по умолчанию слушает только `127.0.0.1`, а не внешнюю сеть.

## Важно

- не добавлять модели Whisper в Git;
- не хранить пользовательские аудиофайлы в репозитории;
- `blank/ui1g` остаётся исходной UI-вёрсткой/референсом;
- правила версионности находятся в `VERSIONING.md`.
