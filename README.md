# REA

Локальный frontend для работы с группами аудиозаписей.

Версия: **0.1.3**.

## Что реализовано

- интерфейс на основе макета из `blank/ui1g`;
- пустое рабочее пространство без демонстрационных записей и мок-данных;
- группы записей в левой панели;
- загрузка нескольких аудиофайлов через выбор файлов или drag-and-drop;
- название группы, дата и purpose/reference;
- локальное хранение аудиофайлов, метаданных, заметок и расшифровок в IndexedDB браузера;
- воспроизведение загруженного аудио;
- waveform и переход по позиции записи;
- синхронизация позиции с сегментами расшифровки;
- таймкоды в отдельной колонке;
- чтение и ручное редактирование расшифровки;
- заметки к конкретной записи;
- metadata файла и группы;
- поиск по списку записей;
- Settings → Local Whisper: локально сохраняемый URL сервиса и проверка подключения через `/health`.

По умолчанию REA проверяет локальный Whisper по адресу `http://127.0.0.1:8787/health`. При успешном ответе показывает статус подключения, модель и устройство, если сервис возвращает эти поля.

Автоматическое распознавание аудио пока не подключено к рабочему процессу REA. В этой версии добавлена только настройка и проверка доступности локального Whisper.

## Локальный запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Vite выведет локальный адрес, обычно `http://localhost:5173`.

Для проверки production-сборки:

```bash
npm run build
npm run preview
```

## Данные

Все пользовательские данные сохраняются только локально в IndexedDB текущего браузера. Аудиофайлы не отправляются на сервер. URL локального Whisper хранится в `localStorage`. При очистке данных сайта в браузере локальные данные REA также будут удалены.

Папка `blank/ui1g` оставлена как исходная UI-вёрстка/референс.
